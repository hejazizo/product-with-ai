# Reference product

The product we build on camera, from idea to launch. Students build their own product in parallel and use this one as a worked example.

**Status:** not chosen yet.

A good reference product:
- needs every part of the course: auth, a database, an AI feature, data and analytics, payments
- is a believable SaaS that someone would pay for
- is small enough to finish, but has real product problems to solve

Candidate: a customer-feedback analyzer that collects feedback, groups it into themes with AI, creates tickets in Linear and shows trends on a dashboard.
