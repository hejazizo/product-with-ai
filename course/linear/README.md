# The course as a Linear backlog

Students import this backlog into their own Linear workspace (free plan) and work through the course by closing tickets. That way they practice product management while taking the course.

Planned contents:
- `backlog.csv`: one issue per lesson, grouped into one project per part, with labels for episode type (Concept, Build-along, Your Turn).
- Import instructions, with screenshots.
- Notes for Jira users.
