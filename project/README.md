# Reference products

The products we build on camera, from idea to launch. There are three, and each one is built with a different amount of AI, so students see the whole range: from code we review line by line to code we never read. Students build their own product in parallel and use these as worked examples.

The rule behind the three levels: **the more a product matters, the more of its code we read.**

| Level | Product | How we work | Code we read |
|---|---|---|---|
| 1 · Built with care | A website with sign-in and a blog | We plan it, the agent builds it, we review every diff | Every line |
| 2 · AI-led, we steer | Shahnameh, explored | We own the design and the key decisions, the agent writes most of it, and tests and evals check it | The key parts |
| 3 · Pure vibe | A game: Tehran Taxi or Rostam's Seven Labours | We describe what we want and play the result | None of it |

## Level 1: a website with sign-in and a blog

The pieces almost every website has, built so we can explain every line of the code:
- sign-up and sign-in, with roles
- a blog: posts, comments and author profiles
- an admin panel
- the usual pages around them: home, about, contact, settings

## Level 2: Shahnameh, explored

A visual, fun way to explore Ferdowsi's Shahnameh that also explains it:
- the stories retold, page by page
- visualizations: maps of where the stories happen, family trees of the heroes and kings, and timelines
- an AI chatbot in a sidebar on every page. It knows which page you're on, so you can ask about the story or character in front of you.

## Level 3: a vibe-coded game

One of these two, still to be chosen:
- **Tehran Taxi:** a driving game in Tehran. Pick up passengers and get them across the city, from Azadi Square to Tajrish, before the clock runs out.
- **Rostam's Seven Labours (Haft Khan):** an adventure game with one level per labour: the lion, the desert, the dragon, the witch, Olad, Arzhang and the White Div.

Students are from Iran, so either game is something they can connect to and keep building after the course.
